# Ctrl Play — Versão 4.0

## Calendário interativo do cronograma
- Substituída a listagem geral do cronograma por um calendário mensal.
- Adicionada navegação para mês anterior e próximo mês.
- Adicionado seletor de mês e ano para consultar períodos específicos.
- Cada dia pode ser selecionado para consultar as aulas daquele dia.
- Indicador visual nos dias que possuem aulas cadastradas.
- Mantido o filtro por turma e as ações de criar, editar e excluir aulas.
- A agenda diária exibe horários, turma, conteúdo previsto, conteúdo ministrado, observações e situação.
- Layout responsivo para telas menores.

## Banco de dados
Nenhuma alteração no banco de dados é necessária nesta versão. As aulas já cadastradas continuam na tabela `aula`.
